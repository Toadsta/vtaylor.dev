A menu bar app for macOS that lets you switch DNS providers in one click: Cloudflare, Google, Quad9, AdGuard, or any custom server you add yourself.

**Install via Homebrew:**

```
brew tap Toadsta/tap
brew trust Toadsta/tap
brew install --cask bardns
```

Forked from [Gregory Linford's DNS Easy Switcher](https://github.com/glinford/dns-easy-switcher).
